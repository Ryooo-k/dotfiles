# React のテスト

- テスト名は日本語で書く
- 正常系・異常系・境界値をカバーする。期待値は仕様から書く
- コンポーネントはレンダリング結果と振る舞い（イベント・状態遷移）を検証する
- API・WebSocket・認証付きの通信などの外部依存はモックする
- 非同期（API・WebSocket）の正常系・失敗系・ローディング状態をカバーする
- 実行コマンドとテストの置き場所は、プロジェクトの `package.json` と既存のテストに合わせる
- コミット前に全テストと lint が通ることを確認する
